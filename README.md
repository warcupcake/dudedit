# Dudedit

Make and edit video by asking. Dudedit is a Mac app for motion design in your brand and for editing your own
footage, with Dude, an assistant that runs on your own Claude account.

This repository only holds the releases. Download the latest `.dmg` from
[Releases](https://github.com/warcupcake/dudedit/releases/latest), open it and drag Dudedit to Applications.

Test builds are not signed by Apple yet: the first time you open one, go to System Settings → Privacy & Security and
choose **Open Anyway**. Dudedit tells you itself when a newer version is out.

Requires a Mac with Apple silicon.
